# Bundled font

`NotoSans-Regular.ttf` is an unmodified Noto Sans font, copyright Google and
licensed under SIL Open Font License 1.1. The original source/license metadata
is retained in `NotoSans-OFL-1.1.txt`. Its Debian-package metadata also mentions
licenses for packaging files; no Debian packaging source is included here.

Source project: <https://github.com/googlei18n/noto-fonts>.
The local input asset was copied from
`.temp/projects/COSMolKit/crates/cosmolkit-depict/assets/fonts/NotoSans-Regular.ttf`
alongside its license file; Chitin does not read that reference path at runtime.

SHA-256: `89c3c497f618fdaa0b2d1e98fef93582f28c71debd2c4a8cdf41f190ced2909d`.

The font is not relicensed as Apache-2.0. Source code remains under the workspace
license. Glyphs in generated drawing documents do not require the application
or output document to adopt the font license, as described by the retained OFL.
